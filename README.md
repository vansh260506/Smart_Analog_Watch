# ⌚ Smart Analog Watch Pro

A beautiful, feature-rich analog wrist watch that automatically detects your location and sets the correct timezone.



---

## ✨ Features

- 🕐 **Realistic Analog Watch** - Smooth sweeping second hand
- 📍 **Automatic Timezone Detection** - Uses Geolocation API + TimezoneDB
- 🌍 **World Clock Mode** - Rotates through 8 global cities
- 🔋 **Battery Indicator** - Shows device battery level
- 🌗 **Theme Support** - Dark/Light mode toggle
- 🔄 **12/24 Hour Format** - Toggle between formats
- 📅 **Date Window** - Classic watch date display
- 📱 **Responsive Design** - Works on all devices

---

## 🛠️ Tech Stack

- **HTML5** - Semantic markup
- **CSS3** - Animations, gradients, responsive design
- **Vanilla JavaScript** - ES6+ modules
- **TimezoneDB API** - Accurate timezone detection
- **BigDataCloud API** - Reverse geocoding
